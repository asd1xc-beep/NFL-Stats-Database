NFL STATS LOOKUP - PORTABLE WINDOWS APP

1. Extract the entire ZIP file to a normal folder such as Documents.
2. Keep all included files and folders together.
3. Double-click "NFL Stats Lookup.exe" to open the app.
4. Use "Update All Data" whenever you want the latest stats and rosters.

The other computer does not need Python or any libraries installed.
An internet connection is required only when updating data.

Use the Game Setup controls to choose home/away teams before game day.
Imported stats are marked YELLOW until manually verified for air.

If Windows displays a security warning, choose "More info" and then
"Run anyway" only if this ZIP came directly from someone you trust.
