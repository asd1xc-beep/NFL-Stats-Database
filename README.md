# NFL Stats Database

This repository contains the original NFL broadcast stats lookup/database tool.

## Project layout

- `nfl_app/` - the NFL stats database app, source code, setup files, and local data folder.
- `ausl_app/` - ignored local copy only, not part of this NFL repository.

## Run locally

From `nfl_app/`:

1. Run `Setup NFL Environment.bat` once.
2. Run `Launch NFL Stats App.bat`.

The app stores generated Excel databases under:

`nfl_app/data/exports/`
